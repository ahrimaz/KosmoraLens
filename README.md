# Kosmora Lens

A read-only quality-of-life overlay for [Kosmora](https://kosmora.io): price history and market stats on hover, ownership and family-tier badges, a fusion planner, and pre-round Pulsar insights.

Lens never buys, sells, bids, trades or plays anything. It only sends rate-limited GET requests using your own session.

## Install

**Chrome / Edge / Brave:** open `chrome://extensions`, enable Developer mode, click **Load unpacked** and select this folder.

**Firefox (140+):** open `about:debugging#/runtime/this-firefox`, click **Load Temporary Add-on…** and select `manifest.json`.

Open the Lens panel with the orb at bottom-right or **Alt+L**.
